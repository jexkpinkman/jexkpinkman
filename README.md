Hey, I'm **Jexk**, a developer from Jakarta, Indonesia.

I build **WhatsApp bots** with Node.js and **Baileys**, and web apps and tools with **Next.js**, React and Node.js. Most of what I make starts from one small, annoying problem: a bot that handles the repetitive chat work, a tool that does one thing well in the browser, a panel that keeps things in check.
